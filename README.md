# BRC20 Documentation

Developer documentation for BRC-20 and BRC2.0 — the programmable Bitcoin token standard and its EVM execution layer.

**[docs.brc20.build](https://docs.brc20.build)**

## Contents

- **Overview** — What is BRC-20, the programmable module, historical context
- **Architecture** — EVM model, account system, contract lifecycle, Bitcoin-native superpowers
- **Protocol** — BRC-20 spec, programmable module spec, BiS AMM
- **Guides** — Deploy tokens and smart contracts, use with AI

## Contributing

The docs are built with [Mintlify](https://mintlify.com). To preview locally:

```bash
npm i -g mintlify
mintlify dev
```
